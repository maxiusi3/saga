# T01两入口流程原型

2026-10-13。依据已确认D04/D05/D11/D13、主计划第4节与B01，以及用户继续升级的授权。本轮原型回答：组织者与讲述者能否看懂下一步、区分本机/云端保存、在中断或整理失败后继续，并在批准前处理来源和分歧？不重新选择产品路线。

## 形态与隔离

采用独立单文件HTML，位于docs/prototypes/2026-10-13-two-entry/index.html，双击可运行。对比方案：正式Next路由易与当前保存能力混淆；静态图无法暴露非法状态；独立可操作演示能探索状态且不进入生产构建。本轮只采用第三种，不修改正式录音页面。

页面常驻“本地流程原型 / Local prototype — fictional examples, no uploads, no recording or AI requests; refreshing resets the demo”。使用虚构家庭Alex和Sam、问题“What do you remember about your first home?”。产品预览使用英语，研究者操作区可中英双语。不要求登录、不请求麦克风、不访问网络，不读取实际文件或家庭资料。全部状态仅在内存，重开恢复通过明确标注的演示动作模拟，不宣称刷新持久化。

## 两条入口与状态

共享纯reducer与显式action，DOM只负责呈现。路径切换/重置清除先前内容、批准与导出状态。所有不适用动作拒绝改变状态并给出原因。

- 导入：选择虚构音频 → 确認使用权与处理范围 → 本机可用 → 上传中 → 云端完整确认 → 文字整理 → 核对 → 批准 → 下载。
- 邀请：显示邀请者/家庭/问题/谁能听 → 模拟认证 → 返回同一个问题（不丢questionId）→ 同意录音与处理 → 开始/暂停/继续/结束/跳过 → 本机保存 → 与导入共用后续流程。可选择“自己讲/家人陪同”，记录差异。
- 保存分别显示本机与云端；上传中、上传失败或原件缺失不能显示云端已确认。中断后仅在已有本机片段时能模拟恢复；没有落盘时明确说明没有可恢复内容。
- AI失败只影响整理，不清理本机或已确认原声；重试不重复原件、故事或已批准版本。无云端原件不可开始处理。
- 审阅固定虚构示例含姓名/约某年与一处年代分歧；来源按钮展开相应片段与时间标记，并显式说明无真实音频。用户可接受、修改、保留双方记忆或暂时跳过。未解决的严重事实不能批准；保留分歧需把正文写为不确定而非采纳有争议的精确年份。家人补充署名保留。
- 批准需要全部严重项已处理且原件完整；批准后尝试重跑AI不能改已批准快照；撤回批准后才能编辑。
- 下载先检查原件完整。缺件返回明确失败，不能显示完整档案成功。演示下载只生成带PROTOTYPE标记的JSON收据（示例来源/决定/状态，不含音频），按钮附近明确说明，并不冒充T02完整原件导出。

## 布局与操作

主题为安静的家庭听述空间：雾绿#f1f6f5、深绿#173632、青绿#256c62、浅绿#e4efec、金色#ddb965、警示红#a63e37。标题Georgia、正文system-ui、时间与状态ui-monospace；不用外部字体/图片。标志性元素是“此设备/家庭云端”双位置保存条，帮助理解真正留下了什么。布局为主流程预览＋研究者情景侧栏，小屏纵排；主按钮至少48px、正文18px、焦点可见，无自动动画。

顶部解释问题和演示边界；状态摘要始终展示角色/入口/认证/问题/同意/本机/云端/整理/审阅/批准/导出。自由操作区提供全部action（非法动作显示原因）。引导情景为真实可点步骤，每个情景从确定初态开始，依次启用下一步：导入完成、邀请认证返回、录音中断恢复、上传失败重试、AI失败但原声保留、分歧/缺件阻止交付。情景切换立即重置，不串用结果。

## 验证与完成边界

按prototype技能保持一次性演示，不增加Jest/Playwright长期测试套件。控制者用浏览器实际操作两入口、失败/恢复/非法动作、批准快照和演示下载，并检查桌面/390px/320px、键盘焦点与网络请求。留下截图、步骤/实际结果与SHA256，独立审查原型规格与实现。

产物完成只表示可开展T01研究；6–8户研究尚需真实安排，不写已招募或验证。G0仍缺远端/账户证据和原型反馈；G1录音/Storage验证独立。本轮不部署、不推送、不操作远端迁移；后续达到里程碑再统一部署，完成一个子任务不能自动视为部署许可。
