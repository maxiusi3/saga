# T00：真实AI失败与录音结果隔离

**依据**：[主计划](../../2026-10-10-integrated-upgrade-plan.md)T00、[决策](../../2026-10-10-upgrade-decisions.md)D01/D08/D13、[基线](../../research/2026-10-11-upgrade-baseline.md)。用户已要求更新文档后开始实施，按现有范围执行。

**目标**：正式调用不再返回模拟故事或合成高置信度；整理失败可见且仍能保存原声；旧录音异步结果不污染新录音。保持真实供应商配置，不在资格未核实前切换模型。

## 文件与行为

| 文件（相对`packages/web/src/`） | 改动与验证 |
|---|---|
| `lib/ai-service.ts`及其测试 | 删除模拟降级；直接请求对应能力；格式无效时报错；置信度缺失不伪造、0不覆盖；状态区分不可用 |
| `lib/ai-response.ts`及路由/服务测试 | 共享的纯响应校验；转写必须为字符串（静默允许空串），生成标题/摘要必须为非空字符串；追问可省略但不补模板，显式null/非字符串数组失败；可选置信度只接受有限的0–1值 |
| `app/api/ai/generate-content/route.ts`及其测试 | 拒绝空/损坏模型结构；取消模板摘要/追问与最低0.7强抬；保留实际返回内容 |
| `app/api/ai/transcribe/route.ts`及其测试 | 不伪造缺省置信度；非法text不能变为空串成功；对象权限后续单独处理 |
| `app/api/ai/health/route.ts`及其测试 | 依据TEXT或OpenRouter、SiliconFlow实际配置报告能力；配置与实测可用性分开，不报告mock |
| `components/recording/ReviewStage.tsx` | 移除虚假音质增强标记，展示处理中/失败/需转写状态；失败时可保存原声和已有文字 |
| `app/[locale]/dashboard/projects/[id]/record/page.tsx`及组件测试 | 每次录音清空旧结果；代际校验拒绝过期resolve/reject；失败状态可见；原声保存与AI完成分离 |

## 2026-10-11首批结果

本计划范围已完成。最终相关回归5套/41项、完整Web 57套/433项、shared 4套/16项和infra 7项通过；`npm run verify`包含的类型检查、lint及构建退出0。代码独立复审无Critical/Important问题；两处Minor已处理：省略追问时不补模板、显式null非法，无转写时明确说明无法准备草稿。

测试包含网络不可用、格式无效、未知/低/零置信度、按能力配置、整理失败保存和旧请求resolve/reject隔离。录音页测试使用真实ReviewStage，但录音器、上传和数据库为测试替身，不代表真机或实际云端耐久性。原声仍须真实保存成功才能宣告保存，浏览器字幕不成为正式ASR。
