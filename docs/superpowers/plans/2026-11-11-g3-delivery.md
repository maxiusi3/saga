# G3 delivery implementation plan

> **For agentic workers:** Use TDD and independent specification/quality review. Independent T09, T10 and T11 domains can be delegated under dispatching-parallel-agents with exclusive file ownership. The parent integrates and runs full acceptance. Do not stage, commit, push, deploy, overwrite historical evidence or migrate a remote database.

**Goal:** Carry approved G2 material through source search and durable offline publication, and connect a server-owned US$59 purchase to verified, reversible entitlements.

**Architecture:** Add forward migrations for publication jobs/snapshots, authoritative search and Stripe order fulfillment. Retain G1 media/deletion guards and G2 immutable review records. Production HTTP and UI call these services; disposable PG, installed Chrome and controlled HTTP providers verify the same code.

**Tech stack:** Next.js/TypeScript/React, PostgreSQL 17.4, Supabase SDK, Stripe SDK, JSZip/streaming archive tools and local PDF rendering.

- [x] **T09 archive delivery.** Own `lib/server/archival-export-service.ts`, export route/tests, new publication job/service/worker files, shared export types and `20261111000001_publication_delivery.sql`. Reproduce truncation and stale/unapproved body export; implement approved content + separately labelled sources, immutable persisted identity and bounded durable archive production. Verify full PDF text/page rendering, original file hashes, repeat download identity, revised approval, deletion/revocation during assembly and job recovery. Add scenarios under `experiments/pg17-g3-delivery/archive-*`; parent wires the complete migration runner.
- [x] **T10 authoritative search.** Own provenance-search module/route/tests, project search client/hub and `20261111000002_authoritative_search.sql`. Reproduce missing newly approved records, forged source/timing, stale corrected transcript and revoked membership. Implement bounded authoritative query with real nullable timing and labelled supplements, atomically versioned current records and protected audio. Add `experiments/pg17-g3-delivery/search-*` native/HTTP scenarios; coordinate parent page changes before editing.
- [x] **T11 purchase fulfillment.** Own payment catalog/routes/tests, purchase page/components/client, new order service and `20261111000003_payment_orders.sql`. Reproduce unsigned/unbound grants, repeated intent creation, refund credits and legacy/trusted-ledger mismatch. Implement persisted request/order identity, actual raw Stripe signature parsing, strict event reconciliation, current order status and source-specific entitlement transitions. Add `experiments/pg17-g3-delivery/payment-*` native/HTTP scenarios using controlled Stripe transport and signed test events.
- [x] **T12 integrated acceptance.** Parent wires `experiments/g1-local/verify-migrations.mjs --g3-delivery --chrome`, deployment migration registry and independent module review. Exercise actual project/purchase components and routes, source playback, offline archive/PDF, negative permissions, job/lifecycle recovery and G1 backup/delete compatibility. Correct old synthetic claims without overwriting historical JSON. Run `npm run verify`, shared and infra; archive immutable source hashes and exact evidence, restore only generated next-env changes, update report/handoff/manual follow-up and final receipt.

Commands: `npm test --workspace=packages/web -- --runInBand <owned-tests>` for behavioral RED/GREEN; `node experiments/g1-local/verify-migrations.mjs --g3-delivery --chrome` for native/Chrome; `node experiments/g1-local/verify-migrations.mjs --story-deletion --chrome` and `--backup` for compatibility.
