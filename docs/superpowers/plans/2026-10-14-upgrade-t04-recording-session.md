# T04 录音会话与块持久化：本地契约

日期：2026-10-14（Asia/Taipei）。承接 [P1 契约](../specs/2026-10-13-upgrade-p1-contracts.md) 第 6 节。

本批先固定浏览器本地会话、块顺序、MIME 选择、上传状态和完整确认的纯函数；随后接入现有 IndexedDB。暂不创建服务端录音会话表，不执行合并任务，不切换生产上传接口，不执行远端迁移。

## 规则

- 会话绑定 `projectId`、`userId`、实际 `mimeType` 和开始时间；恢复时项目和用户必须精确匹配。
- 块按数字 index 排序，不能重复或跨会话；保存块的动作先于上传标记。
- 上传成功只将块标为 `uploaded`，不自动清理本地恢复副本；完整确认前保留块。
- 只有从 index 0 开始连续、字节数有效、所有块已上传的会话才能进入 `confirmed`。
- MIME 选择只从浏览器显式支持的候选中选择；无候选时返回空并由界面显示真实失败。
- 纯函数返回新快照，不修改调用者输入；未知项目/用户和非法状态全部拒绝。
