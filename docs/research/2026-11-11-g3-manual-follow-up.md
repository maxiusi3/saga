沿用用户确认的本地环境／虚构账号／安装版 Chrome Web 验收口径。人工门禁为 **waived_by_user**，不阻塞已完成的本地 G3；以下没有记为实测完成，也不因本地通过自动放行真实收费或部署。

| 项目 | 当前边界 | 后续证据 |
| --- | --- | --- |
| 真机与家庭体验 | Chrome 桌面和 390px 布局通过 | iOS Safari、Android Chrome、辅助技术、第二实体设备离线打开，6–8 户真实体验与本人核听 |
| 真实支付 | 实际 Stripe SDK、受控 loopback HTTP、合成签名通过；仅 test mode | Stripe.js 卡片输入、SCA／跳转、真实 Stripe test 账户／Webhook 投递，再经发布门确认真实收费 |
| 商业范围 | 测试商品页显示单讲述者、120 分钟／20 张照片／12 月；真实条款未确认 | 依据真实成本确认额度、编辑／交付次数、退款及续期边界；测试目录不是线上素材配额强制执行的证据 |
| 对账与请求基础设施 | 未绑定支付超过 23 小时、部分退款先到会保留待对账；不重复发权益 | 对账运维流程、慢请求体和供应商中断行为、代理请求超时策略 |
| 托管归档 | 私有共享磁盘＋长驻 Worker 在本地通过 | 实际生产下载主机／Worker 共用持久卷、重启监督、磁盘配额、容量和灾难恢复；单独部署 Web 不会运行 Worker |
| 托管 Supabase | 完整根迁移及 ACL 在原生 PG17.4 通过；本地配置含 invitation_candidate | 托管 PostgREST 暴露 schema／缓存、真实 Auth／Storage、RLS、完整数据库和私有卷备份恢复 |

| 来源权限与删除 | 重新请求会校验撤权／纠正／墓碑，实际私有 ZIP 删除通过 | 已发短期签名 URL 的存活窗口、供应商对象／版本保留期、用户已下载副本不能远程撤回 |
| 模型与语义检索 | 字面来源检索通过；语义模型为 unavailable_unmeasured | 真实转写／家庭忠实度，未来语义方案的授权、质量与成本；不把字面匹配描述为模型答案 |
