# G2 人工后补与证据边界

本批沿用用户授权：本地搭建环境与合成账号，以安装的 Google Chrome 自动化 Web 结果验收。人工门禁状态统一为 **waived_by_user**；未执行项不记为实测通过，也不阻塞本地工程推进。

| 后补项 | 负责人 | 要补的真实证据 |
| --- | --- | --- |
| 供应商账户与政策 | 负责人／运维 | 实际 ElevenLabs 账户、地区、隐私／训练／保留设置与政策证据；当前只验证配置合同与本地受控 HTTP |
| 真实语音与模型质量 | 负责人／授权家庭 | 获得同意的真实口述、姓名／年代／地点／否定／不确定性样本；独立核听时间码、说话人和转写内容；本批合成音不能证明语义正确 |
| 家庭审阅体验 | 用户／授权家庭 | 多位家人实测接受、修正、争议并列和最终批准；核实署名和文稿是否符合本人记忆 |
| 物理设备 | 用户 | iOS Safari、Android Chrome、真实麦克风、锁屏／来电／后台切换及辅助技术；390px 桌面视口只证明窄屏布局 |
| 托管环境 | 运维 | 真正的 Auth、PostgREST、Storage 签名范围读取、RLS、迁移与备份恢复；本轮仅在本地完整 PG17.4 schema 执行 |

未知 ASR 结果会持久保留 pending，同一或新请求 ID 均不自动重发。当前没有运营侧查供应商结果并解除 pending 的界面；这是明确的后续工程，不要求用户通过重复点击处理。未确认外部结果前保留原件与请求记录。

本批没有真实付费 ASR、真实家庭留出集或实际成本观测。10 月旧评估中“10 户／200 个错误／100 次回听”来自模板或常量，不能替代上述证据。历史 JSON 保持原样；新的评估输出明确标注 synthetic／unmeasured，真实质量门不置为通过。

本轮未暂存、提交、推送、远端迁移或部署。G1 人工项继续见 [G1 后补清单](2026-11-09-g1-manual-follow-up.md)。
