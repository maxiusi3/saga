# T04 SmartRecorder：本地会话接入记录

日期：2026-10-14（Asia/Taipei）。承接[会话数据层记录](2026-10-14-t04-recording-session-local-implementation.md)及[接入计划](../superpowers/plans/2026-10-14-upgrade-t04-smart-recorder.md)。本批修改应用录音入口的本地持久化行为，尚不证明线上部署或 G1 通过。

## 这批改变了什么

- `SmartRecorder.tsx`：浏览器显式探测 WebM/MP4/Ogg，保存 MediaRecorder 返回的实际 MIME；会话绑定项目和当前登录用户（不以 storyteller 代替登录者），会话写入成功才开始采集。
- `local-recording-session.ts`：每次采集独立管理本地写入队列与上传队列。逐块计算真实 SHA-256 并保存 Blob、大小、索引和时间，落盘提交完成后才开始上传。慢上传不会阻塞下一块落盘。
- 上传成功只标记 `uploaded`，失败保留 `pending`；联网事件与定时补传共享同一上传任务，跳过已上传块，不删除本地副本。
- `storage.ts`：临时块上传携带 `expectedUserId`，在 StorageService 获取当前认证用户后检查身份，防止账号切换期间写入另一账号目录。该可选检查保持其他上传调用兼容。
- 停止录音等待最后一次 `dataavailable` 写入后才显示预览。会话保留 `interrupted`（在现有三态模型中表示已停止但未确认），不会写入 `confirmed` 或资产 ID。
- 浏览器错误、页面退出、组件卸载、项目/账号变化均保留未确认会话；旧回调按采集代次隔离。权限申请或初始会话写入仍在等待时退出，也会释放已取得的麦克风。项目变化清除旧转写和预览。
- 实时转写网络失败只报告转写不可用，不再自动停止并重启音频采集。
- `recording-session.ts` 移除没有 MediaRecorder 能力证据时的格式猜测。

## 验证证据

1. 旧 SmartRecorder 对首批 10 项新契约测试全部失败；实现后 10 项通过。
2. 移除上传用户检查、保留旧 MIME 猜测时，两个边界测试按预期失败；修复后通过。
3. 自查补充的“初始会话写入期间卸载”和“项目切换清理旧转写”均先观察到失败，再修复通过。
4. 最终定向：4 套 / 36 项通过，包含录音页面既有回归、18 项 SmartRecorder 契约、8 项会话纯函数和 2 项上传用户检查。随后补充唤醒锁延迟释放、重复可见性请求、晚到锁释放和浏览器主动释放回归，定向 SmartRecorder 为 1 套 / 24 项通过；真实 Blob 和 SHA-256 运算，浏览器设备、IndexedDB 和 Storage I/O 使用测试替身。
5. 最终项目级 `npm run verify`：退出 0；70 套 / 615 项 Web 测试通过，类型检查、lint、Next 构建和 175 个页面生成完成。构建仍报告缺少 `SUPABASE_SERVICE_ROLE_KEY`、Next 配置弃用和多 lockfile 根目录推断提示；这些不构成生产配置或远端 schema 证据。构建后已恢复 `packages/web/next-env.d.ts`，`git diff --check` 通过。
6. 本轮审查发现并修复唤醒锁生命周期：释放前同步放弃旧引用；旧锁的异步 `release()` 不会清掉新锁；已有锁或在途请求会复用，重复可见性事件不会遗失 sentinel；取消期间晚到的锁会释放。相关回归现已通过；没有提交、推送、部署、远端迁移或真实供应商调用。

本轮全部保留在既有 `codex/october-upgrade-p0` 工作树，没有提交、推送、部署、远端迁移或真实供应商调用。

## 仍未证明的边界

- IndexedDB 真浏览器 v1→v2 升级、重开读取、配额和真实设备生命周期尚待实际演练；本批 mock 不代替这些证据。
- 仍使用 60 秒录音切片。页面退出写入属于尽力保存；浏览器强杀可能丢失尚未发出的片段，不能承诺零丢失。
- 暂存 Storage 上传仍为旧临时块路径及 `upsert:false`。远端写入成功但响应丢失时，本地保持 pending；尚无服务端对账、幂等完成确认或自动清理。
- 没有加入恢复会话选择/回听界面，没有把新 MediaRecorder 的独立容器追加到旧容器，也没有服务端会话、重组、容器解码和时长验证。
- `onRecordingComplete` 仍接既有录音审阅/保存流程，代表本地录音结束；不等于 T02 音频资产 ready、不等于校验过的可交付原件。T04 的新完整确认和 T02 正式资产入口仍未接入。
- 临时上传用户检查不是项目 RLS、撤权、备份或供应商删除的验收。P0/G0/G1、远端 schema/Storage 和真机矩阵仍维持未验证。
