## 范围与接口

`verifyRecordingJobInput(jobId, serverOptions)` 只接受任务 ID 作为业务输入。服务端配置数据库客户端、Storage 原点/凭证、FFmpeg 路径与资源上限，不信任请求传入的用户、清单或对象路径。

1. 从持久任务、资产、会话 `seal_input` 和分块账本还原输入，核对固定身份、状态、版本、规范清单摘要、幂等键及当前项目/讲述者/故事归属/删除状态。
2. 按清单的真实物理路径读取私有对象，禁用重定向与缓存。核对 HTTP 完整响应、逐块字节数与 SHA-256，原样流式拼接临时文件，再用现有 FFmpeg 全流解码器核验。
3. 在读取前、响应头后、块读完后、解码前及返回证据前重新检查账本和授权。超时、取消、缺块、损坏、撤权或删除均拒绝；释放流和临时文件。
4. 只返回 `input_verified`、核验数据及 `canClearLocalDrafts:false`；不返回临时文件路径、不调用内存任务执行器、不写数据库或 Storage。

## 明确限制

- 多次只读检查是乐观一致性保护，不是数据库与对象存储间的原子撤权/删除屏障。内容由 SHA-256 固定，不等于对象版本的事务锁。
- 只核验当前 `queued` / `verifying` / `sealing` 输入。持久领取、租约、心跳、失败落库、结果上传与原子发布仍是后续切片，未接正式 Worker 调度或公开 HTTP 入口。
- 本地合成音频与 HTTP 夹具不是远端 PostgREST/RLS/Storage 验收，不是真机长录音、核听、尾部完整性或云端持久确认。FFmpeg 仍需独立部署与进程隔离。
- 2000 块只通过账本分页单测，完整 verifier 目前只实测 13 块音频。每块多次全量重读账本具有二次增长的数据读取成本，接生产前必须压测并设计有界重验证；不能把分页单测当成长录音吞吐验收。
- AbortSignal 取消保证本地查询链中断和不再发起后续请求，不证明远端已经执行的 SQL 被终止。
- `g1Item01Complete:false`、`g1MilestoneSatisfied:false`、`pushConditionSatisfied:false`。不推送、不合并 main、不远端迁移/repair、不部署、不付费调用、不外发家庭素材。
