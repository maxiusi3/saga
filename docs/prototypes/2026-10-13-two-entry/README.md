# 两入口本地流程原型

双击[index.html](index.html)打开即可；不安装依赖，不连接服务器。默认英语产品预览，研究操作区用于模拟故障和状态。所有人物/文字均为虚构，不上传、不请求麦克风、不调用AI；刷新会重置。页面内“重开/恢复”只模拟已持久化状态，并非真实恢复能力。

探索的问题：导入已有声音或受邀讲述后，用户能否理解此设备与云端分别保存了什么，处理整理失败、来源分歧和缺件，再决定批准/下载？

从顶部选择入口，或在引导情景中顺序点步骤。自由操作可尝试任何动作；当前不合法的动作会说明原因并保持原状态。来源只显示虚构文本与时间标记，没有真实声音。下载仅导出带PROTOTYPE标记的JSON演示收据，不含原件、不是完整档案。
